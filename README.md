# Abertura de Caminhos — edição outubro de 2026

Landing page estática pronta para publicação no GitHub Pages.

## Antes de publicar

Substitua, em todos os arquivos, o endereço abaixo pelo domínio público definitivo da página:

```text
https://SEU-DOMINIO.com.br/
```

Ele aparece no `index.html`, nas páginas legais, no `sitemap.xml` e no `robots.txt`. Preserve o protocolo `https://`. Se o projeto ficar em uma subpasta do GitHub Pages, inclua essa subpasta no endereço final.

Exemplo:

```text
https://seuusuario.github.io/abertura-de-caminhos/
```

## Publicação

1. Envie todo o conteúdo desta pasta para a raiz do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Selecione a branch de publicação e a pasta raiz.
4. Depois que a página estiver no ar, confirme se `sitemap.xml` e `robots.txt` abrem normalmente pelo navegador.
5. Compartilhe a URL em um teste de WhatsApp para conferir a prévia social.
